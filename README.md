# לוח דיגיטלי לבית הכנסת

לוח מסך מלא לבית הכנסת: זמני תפילות, זמני היום, פרשה והפטרה, חגים, אזכרות, פרנסים, הודעות, שעון נץ, ספירת העומר ועוד. הגבאי מעדכן מהטלפון, והלוח מתעדכן תוך שניות. הלוח עובד גם בלי אינטרנט.

| דף | מה יש בו |
|---|---|
| `index.html` | הלוח עצמו – לפתוח על המסך בבית הכנסת |
| `admin.html` | ממשק הגבאי – לפתוח בטלפון או במחשב |
| `m.html` | דף למתפללים – לשתף בקבוצת הוואטסאפ של בית הכנסת |

תוכנית העבודה המלאה: [`docs/PLAN.md`](docs/PLAN.md).

---

## 1. התחלה מהירה (בלי ענן, 5 דקות)

1. מעלים את התיקייה לאחסון סטטי (פרק 3), או פותחים מקומית עם שרת קטן:
   ```bash
   npx serve .        # או: python3 -m http.server 8080
   ```
2. פותחים `admin.html`, מעדכנים פרטים ושומרים.
3. פותחים `index.html` – רואים את הלוח.

במצב הזה הנתונים נשמרים **בדפדפן שבו ערכת**. טוב להדגמה, או כשהגבאי מעדכן ישירות על המכשיר של הלוח. לעדכון מהטלפון צריך את Supabase (פרק 2).

## 2. חיבור Supabase (עדכון מהטלפון)

1. נרשמים ל-[supabase.com](https://supabase.com) ופותחים פרויקט חדש (התוכנית החינמית מספיקה).
2. **SQL Editor → New query** → מדביקים את כל התוכן של `supabase/schema.sql` → **Run**.
3. **Project Settings → API**: מעתיקים את `Project URL` ואת המפתח `anon public`.
4. ממלאים ב-`config.js`:
   ```js
   supabaseUrl: 'https://xxxx.supabase.co',
   supabaseAnonKey: 'eyJ...',
   boardId: 'ohel-moshe-haifa',   // שם קצר באנגלית לבית הכנסת
   ```
5. פותחים `admin.html` → **הרשמה ראשונה** עם אימייל וסיסמה → נכנסים → מעדכנים → **שמור**. השמירה הראשונה יוצרת את הלוח, ואתה הבעלים שלו.
6. (מומלץ) ב-Supabase: **Authentication → Providers → Email** – לכבות "Allow new users to sign up" אחרי שנרשמת, כדי שאף אחד אחר לא ייצור חשבונות.

> המפתח `anon` מותר לחשיפה בקוד – ההרשאות נאכפות בשרת (קריאה לכולם, עריכה רק לבעלים ולגבאים שהוספת). לעולם אל תשים בקוד את המפתח `service_role`.

**גבאי נוסף:** שיירשם דרך `admin.html`, ואז להריץ ב-SQL Editor את הפקודה שבסוף `schema.sql` עם האימייל שלו.

## 3. העלאה לאוויר (חינם)

**GitHub Pages:**
1. יוצרים repo חדש ומעלים את כל הקבצים.
2. **Settings → Pages → Branch: main / root → Save**.
3. הכתובת תהיה `https://<user>.github.io/<repo>/`.

**Netlify:** גוררים את התיקייה ל-[app.netlify.com/drop](https://app.netlify.com/drop).

חובה כתובת `https` – בלעדיה לא יעבדו העבודה בלי אינטרנט והמיקום מהטלפון.

## 4. התקנה על סטרימר (עלייה אוטומטית ללוח)

מתאים לסטרימר מבוסס Android TV / Google TV (Xiaomi TV Box, Chromecast with Google TV, Nvidia Shield) ול-Fire TV.

1. בסטרימר: מתקינים את **Fully Kiosk Browser** (מחנות Google Play; ב-Fire TV דרך Downloader מהאתר fully-kiosk.com).
2. **Settings → Web Content Settings → Start URL**: כתובת הלוח, למשל `https://<user>.github.io/<repo>/index.html`.
3. **Settings → Device Management**:
   - **Launch on Boot** – פועל (הלוח עולה לבד כשמדליקים את הסטרימר)
   - **Keep Screen On** – פועל
4. **Settings → Web Content Settings → Enable Fullscreen Mode** – פועל.
5. **Settings → Advanced Web Settings → Reload on Internet Reconnect** – פועל (מומלץ).
6. בטלוויזיה: להגדיר שמקור הקלט עולה על ה-HDMI של הסטרימר, ולכבות מצב חיסכון/כיבוי אוטומטי. אם יש בטלוויזיה טיימר הדלקה – אפשר לחבר אותו לשעות התפילה.

> חלק מההגדרות המתקדמות ב-Fully Kiosk דורשות רישיון Plus (תשלום חד-פעמי קטן). שמות התפריטים עשויים להשתנות מעט בין גרסאות.

**חלופה – מיני-PC או Raspberry Pi:** מפעילים את Chrome במצב קיוסק בהפעלה:
```bash
chromium --kiosk --noerrdialogs --disable-infobars --autoplay-policy=no-user-gesture-required https://<כתובת>/index.html
```

## 5א. עיצובים ורקעים

כל הרקעים והאיורים מקוריים ומצוירים בקוד (`js/art.js`), כך שאין קבצי תמונה לטעון והם עובדים גם בלי אינטרנט.

- **רקעים:** ירושלים העתיקה בשקיעה, אבני הכותל (עם מסגרות הסיתות ואזוב בין האבנים), היכל עם עמודי שיש ופרוכת קטיפה, וחיתוך נייר בסגנון כתובה. "אוטומטי" בוחר לפי ערכת העיצוב.
- **מסך ברכה** שמופיע מעצמו לפי התקופה: שבת שלום (פמוטים, חלה וגביע), חנוכה (החנוכייה דולקת לפי הלילה), סוכות (לולב ואתרוג), ראש השנה ויום כיפור (שופר, תפוחים ודבש), פורים (מסכות ואוזני המן), פסח (קערת הסדר ומצות), שבועות (אלומת חיטים ופרחים), ראש חודש ואלול.
- **תמונה משלך:** בממשק הגבאי → תצוגה → "תמונת רקע משלך" – כתובת לתמונה (למשל צילום של ארון הקודש בבית הכנסת שלך). גוברת על הרקע המצויר.

## 6. איך מוגדרים זמני תפילות

כל תפילה שייכת ל"לוח": חול, ערב שבת, שבת, ראש חודש, חול המועד, ערב חג, חג, תענית, חנוכה.

- בימים רגילים מוצג לוח החול / ערב שבת / שבת.
- ביום מיוחד (למשל ראש חודש), תפילה מלוח ראש חודש **מחליפה** תפילה **באותו שם** מלוח החול, והשאר נשארות. כך מספיק להגדיר בראש חודש רק "שחרית".
- **שעה קבועה** – למשל 06:30.
- **יחסית לזמן** – למשל 15 דקות לפני השקיעה, עיגול ל-5 דקות כלפי מטה, ו"קבוע לשבוע" (לפי השקיעה המוקדמת בשבוע, כדי שמנחה לא תזוז כל יום).

ליד כל תפילה יחסית מוצגת השעה שיצאה היום – כדאי לבדוק אותה מול לוח של הרב.

## 7. בדיקות לפני הפעלה

- [ ] להשוות את זמני היום ללוח של רב הקהילה / לוח "אור החיים" לאותה עיר (הפרש של עד דקה מקובל).
- [ ] להריץ את הלוח עם `?date=` על שבתות וחגים: שבת שקלים, זכור, חזון, ראש השנה, סוכות, פסח, תשעה באב.
- [ ] לנתק את האינטרנט מהסטרימר ולוודא שהלוח ממשיך לעבוד (נקודה אדומה קטנה בפינה = אין חיבור).
- [ ] לשמור שינוי מהטלפון ולראות שהוא מופיע בלוח.
- [ ] להתייעץ עם רב בית הכנסת על מיקום המסך ועל פעולתו בשבת (הלוח לא דורש שום נגיעה בשבת).

## מבנה הקוד

```
config.js          הגדרות התקנה (Supabase, מזהה הלוח)
index.html         הלוח        → js/board.js, js/screens.js, css/board.css
admin.html         ממשק גבאי   → js/admin.js, css/admin.css
m.html             דף נייד     → js/mobile.js, css/mobile.css
js/jewish.js       זמנים, תאריך עברי, פרשה, הפטרה, חגים, עומר, שינויים בתפילה (Hebcal)
js/prayers.js      חישוב זמני תפילות ושיעורים
js/store.js        Supabase / שמירה מקומית, עדכון חי, עבודה בלי חיבור
js/defaults.js     ברירות מחדל ונתוני הדגמה
sw.js              עבודה בלי אינטרנט
supabase/schema.sql
```

אין שלב build ואין תלויות להתקנה: הספריות (Hebcal, Supabase) נטענות מ-jsDelivr בגרסאות נעולות, ונשמרות במטמון.
