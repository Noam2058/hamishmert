# תוכנית עבודה – לוח דיגיטלי לבית הכנסת

## מטרה
לוח דיגיטלי עצמאי לבית הכנסת: מסך מלא על סטרימר או מחשב קטן, שמחשב לבד זמנים, פרשה וחגים, והגבאי מעדכן אותו מהטלפון. כל התכולות ממסמך המחקר.

## החלטות ארכיטקטורה
| נושא | החלטה | למה |
|---|---|---|
| מבנה | אתר סטטי, JavaScript נקי בלי שלב build | רץ על כל דפדפן, כולל סטרימר ישן; אחסון חינמי (GitHub Pages / Netlify) |
| חישובי לוח שנה | ספריית Hebcal (@hebcal/core, leyning, learning) מ-jsDelivr | ספרייה פתוחה ובדוקה: זמנים, פרשה, הפטרה, חגים, תחנון, הלל, עומר, דף יומי, יארצייט |
| נתונים | Supabase: טבלה `boards`, שורה אחת לכל בית כנסת (JSON) | פשוט, עדכון חי (Realtime), הרשאות לפי משתמש |
| מצב בלי ענן | אותו קוד עובד גם בלי Supabase (שמירה מקומית + ייצוא/ייבוא) | הדגמה, ובית כנסת שלא רוצה ענן |
| אופליין | Service Worker שומר את הקוד והספריות, והנתונים האחרונים נשמרים מקומית | הלוח ממשיך לעבוד בלי אינטרנט, כולל בשבת |
| גודל מסך | "קנבס" של 1920×1080 שמותאם לכל מסך | אותו עיצוב על כל טלוויזיה |
| הפעלה בסטרימר | Fully Kiosk Browser עם הפעלה אוטומטית | עולה ישר ללוח בכל הדלקה |
